# UranXSU

A KernelSU fork based on [BakaSU](https://github.com/Baka-SU/BakaSU) with Material 3 Expressive UI.

[![Latest release](https://img.shields.io/github/v/release/UIRAN23/UranXSU?label=Release&logo=github)](https://github.com/UIRAN23/UranXSU/releases/latest)

## Features

- Built-in SUSFS manager (built-in SUSFS and SusFS LKM)
- Built-in NoMount (VFS redirection, upstream-compatible) mount engine
- Built-in Zygisk (NyaZygisk) with settings
- Dynamic manager: any installed app can be a manager
- Module banners, custom texts, home screen customization
- SukiSU-Nova `.sukisu` theme import/export
- Two app icons: default and Miku Nakano
